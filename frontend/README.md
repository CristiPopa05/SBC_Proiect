# AI Sign Camera

Bord digital cu cameră live și un slot pentru indicatorul recunoscut de YOLO. Interfața a fost importată din proiectul [AI Sign Camera din Lovable](https://lovable.dev/projects/e0103dab-bc45-44e3-b16e-0b2602115c4a).

Pentru pregătirea modelului, pornirea detectorului Python și rularea interfeței, urmează [instrucțiunile proiectului](../PLAN.md#rulare-locală).
